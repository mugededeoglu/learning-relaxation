\# Root-Node Experimental Results



This directory contains the experimental outputs for root-node relaxation selection in nonconvex quadratically constrained quadratic programming (QCQP).



The experiments evaluate supervised classification and regression methods, including feature-based machine learning models and graph neural networks (GNNs), for selecting between LP and semidefinite-based relaxations.



\## Directory Overview



| Directory | Description |

|---|---|

| `clf\_outputs\_txt\_features\_synth\_gnn/` | Feature-based classification results associated with synthetic instances. |

| `clf\_outputs\_txt\_features\_synthmissings/` | Classification outputs for an additional synthetic experimental configuration. |

| `clf\_outputs\_txt\_features\_synthprime\_gnn/` | Feature-based classification results associated with Synthetic′ instances. |

| `gnn\_clf\_outputs/` | GNN classification experiment outputs. |

| `gnn\_clf\_outputsprime/` | GNN classification outputs associated with Synthetic′ experiments. |

| `gnn\_reg\_outputs/` | GNN regression experiment outputs. |

| `gnn\_reg\_outputsprime/` | GNN regression outputs associated with Synthetic′ experiments. |

| `reg\_outputs\_txt\_features\_gnn\_synth/` | Feature-based regression outputs associated with synthetic instances. |

| `reg\_outputs\_txt\_features\_gnn\_synth\_prime/` | Feature-based regression outputs associated with Synthetic′ instances. |



\## Notes



The directory contains saved outputs from different experimental configurations. The results should be interpreted together with the experimental definitions and evaluation methodology provided in the accompanying manuscript.
